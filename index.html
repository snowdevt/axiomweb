Setup

Three steps, then you're scripting.

Works with Delta and Fluxus. You bring your own API key, so you stay in control of the model and the cost.

1

Enter your API key

Add your OpenRouter or Gemini API key in the Axiom app settings.

OpenRouterGemini
2

Paste the Cloud Bridge script

Paste the Axiom Cloud Bridge script into Delta or Fluxus and run it. This is what lets Axiom test and fix code inside your game.

axiom_bridge.lua Luau 
print("Axiom Bridge Started. Waiting for scripts...")
while task.wait(1) do
    pcall(function()
        local req = request or syn.request or http_request
        if not req then return end

        local res = req({
            Url = "http://127.0.0.1:6969/get_script",
            Method = "GET"
        })

        if res and res.StatusCode == 200 and res.Body and res.Body ~= "" and res.Body ~= "Queued" then
            print("Axiom: Got a script, executing...")
            local func, err = loadstring(res.Body)
            if func then
                pcall(func)
                print("Axiom: Execution finished.")
            else
                print("Axiom Load Error: " .. tostring(err))
            end
        end
    end)
end

Open the overlay and start typing

Open the floating overlay on top of your game and describe what you want. Axiom handles the rest.
